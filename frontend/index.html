ARGUS-9 SCORING ENGINE

This dashboard aggregates live open-source indicators using a Two-Speed Risk Model. It does not reflect proprietary intelligence or predictive certainty.

1. STRUCTURAL PRIOR (40%) Baseline country and border risk values initialized from historical conflict frequencies (UCDP/PITF statistics).
2. BEHAVIORAL EVENT LAYER (60%) Weighted moving average of active domain indicators. Normalization scales raw metrics to percentiles against 30-day baselines.
3. CLUSTERING PENALTY Simultaneous elevation across 3 or more domains triggers a synergy multiplier to reflect high-confidence correlation.
4. LAG ASYMMETRY Escalation signals trigger immediate index increases, while de-escalation fades out slowly via exponential decay.
